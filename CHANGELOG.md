DIOS 0.8.0 - 26 Nov, 2026
-------------------------
- **Kernel**:
  - Standard output channels and the corresponding syscalls: `SYS_CH_CREATE`, `SYS_CH_READ`, `SYS_CH_STAT`, `SYS_CH_CLOSE`
  - New syscalls `SYS_SPAWN`, `SYS_CHDIR`, `SYS_STR`, `SYS_TASK_ALIVE`, `SYS_REALPATH`
  - Unique working directory per process
  - `uptime` kernel command removed, use `time -u` instead
  - Automatically start the graphics mode after boot if `gfx` kernel argument specified
- **ulib**:
  - New functions `uspawn`, `uchdir`, `usysstr`, `utaskalive`, `urealpath`, `chCreate`, `chRead`, `chWriters`, `chClose`
- **Userspace**
  - `echo`, `about`, `pwd`, `ls`, `touch`, `mkdir`, `rmdir`, `rm`, `mv`, `cp`, `write`, `append`, `file` are now built-in programs
- **GTerm**:
  - A new built-in program `gterm.elf`, a graphical terminal.
- **Blackboard**:
  - A new built-in program `blackboard.elf`, a simple sketching application.

DIOS 0.7.0 - 26 Nov, 2026
-------------------------
- **Kernel**:
  - **ABI breaking change**: syscall numbers were changed. Now they are grouped by 100
  - Experimental FAT32 writing support. Drives are mounted as read-only by default, to enable writing run e.g. `remount usb0p1 rw`
  - File writing syscalls: `SYS_FWRITE`, `SYS_UNLINK`, `SYS_MKDIR`, `SYS_RMDIR`, `SYS_RENAME`, `SYS_SYNC`
  - New shell commands: `touch`, `mkdir`, `rmdir`, `rm`, `mv`, `cp`, `write`
  - Recovering from USB transaction errors
- **ulib**:
  - File writing functions: `ufwrite`, `uunlink`, `umkdir`, `urmdir`, `urename`, `usync`
  - TGA loader (`ulib.gfx.tga`)
  - Improved `uprintf`: leading zeros, `%k`, `%X`.
- **Build System**:
  - Improved `build.py`. It now compiles ulib and the userspace: a single `python build.py` builds the entire system at once. Build parameters are taken from `build.toml` config.

DIOS 0.6.0 - 25 Nov, 2026
-------------------------
- **Kernel**:
  - `/` is now a read-only virtual root FS loaded from an archive (`rootfs.tar`) provided by the bootloader. `rootfs.tar` is generated by the `build.py` script after kernel compilation from the contents of the `rootfs` directory
  - Multi-mounting. Disk volumes are now mounted as virtual directories under `/mnt` (e.g. `/mnt/usb0p1`)
  - Sector cache for block devices that speeds up USB reads
  - The kernel looks for programs in `/bin`
  - `gfxd.elf` is not a boot module anymore, it is now stored in the rootfs as `/bin/gfxd.elf`
- **GFXD**
  - Window decorations and dragging
  - Cursor is now loaded from `/etc/gfxd/cursor.tga`
  - Many performance improvements.

DIOS 0.5.0 - 24 Nov, 2026
-------------------------
- **Kernel**:
  - User-space graphics server support. Kernel now can give ownership of the screen to a userspace service. `Ctrl+F1` switches back to the shell, `Ctrl+F2` shows the server, `Ctrl+F3` stops it
  - New system calls `SYS_DATETIME`, `SYS_RANDOM`
  - Syscall extension hooks
- **ulib**:
  - `ulib.gfx`, a graphics API. `ulib.gfx.proto` provides a kernel graphics protocol; `ulib.gfx.canvas` implements a simple 2D canvas; `ulib.gfx.window` implements a window abstraction
  - New functions `urandom`, `memcmp`,  `alignUp`, `alignDown`, `uputi`, `uprintf`, `udatetime`
  - Buffered standard output
- **GFXD**
  - A userspace graphics server. Not much is implemented in it at the moment, but it already allows applications to render something on the screen.

DIOS 0.2.0 - 21 Nov, 2026
-------------------------
- Basic ELF64 userspace programs support. They are currently loaded by Limine as kernel modules (the kernel itself doesn't have a file system)
- CMOS date-time reading
- More kernel shell commands
- Switch to Python for building.
