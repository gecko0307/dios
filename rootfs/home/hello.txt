Welcome to DIOS!

You have successfully launched DIOS, an operating system written in D programming language.

DIOS stands for Desktop-oriented Independent Operating System. It does not replicate either Unix or Windows. While some parts of the system are modeled after Unix and others are inspired by Windows, this is only to keep a degree of familiarity with existing systems for better user experience. The goal is not to create a complete clone of any existing architecture. The purpose of DIOS is experimenting with system APIs and desktop environment design.

Please keep in mind that DIOS is an experimental project currently under active development. Not all system features may function in the way you are accustomed to.
